# GreenCross Pharmacy — Landing Page (Standalone)

Finished HTML, CSS and JavaScript you can host anywhere — no build tools, no install.

## What's inside

- `index.html` — the full page (hero, essentials, quick answers, testimonials, contact)
- `styles.css` — all styling (green pharmacy theme, mobile-friendly)
- `script.js` — page content and the WhatsApp enquiry form
- `assets/hero-pharmacy.png` — hero image
- `favicon.ico` — browser tab icon

## How to use

1. Unzip the folder.
2. To preview, open `index.html` in any browser (double-click it).
3. To put it online, upload the whole folder to any web host (cPanel, Netlify, Vercel, Cloudflare Pages, etc.).
